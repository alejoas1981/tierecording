# План: TIE спокойно

Русскоязычный интерактивный помощник для людей в Испании, которым нужно подготовиться к оформлению карты TIE после одобрения ВНЖ. Главная задача — превратить разрозненные инструкции в ясные следующие шаги. Продукт не получает свободные слоты, не ведёт мониторинг, не бронирует приём и не гарантирует его; он не заменяет юриста или официальное ведомство. Сроки и персональный правовой статус не вычисляются.

## Реализация

React + TypeScript в имеющемся статическом шаблоне: одна страница с переключаемыми экранами. Данные чек-листа и журнала ручных проверок сохраняются только в localStorage браузера; никаких паспортов, NIE, номеров дел, адресов, паролей, SMS или сканов сервис не запрашивает. Всё доступно без входа. Пользователь самостоятельно переходит на официальный портал и проверяет актуальность и применимость требований. Функции: последовательность шагов, чек-лист основных документов на основе сайта полиции с пометкой об уточнении в отделении, явная кнопка портала, ручной журнал попыток с удалением, безопасный нейтральный шаблон на испанском с копированием, справка по срочному случаю и подтверждённые официальные источники с датой проверки. Печатная версия создаётся функцией браузера. Фиксация попыток не является юридическим доказательством или гарантией соблюдения сроков. Ссылки должны открываться наружу в отдельной вкладке, кнопки должны выполнять только обещанное.

Структура: `client/src/pages/Home.tsx` — композиция и логика вкладок; `client/src/components/tie/` — данные и отдельные разделы; `client/src/index.css` — дизайн; `client/public/alekseysavchenko-routes.json` — единственный маршрут. Статическая сборка из стандартного Vite.

## Дизайн

Три варианта: 1. Средиземноморский редакционный минимализм, вероятность 0,06. 2. Технический канцелярский минимализм, вероятность 0,04. 3. Мягкий альманах с элементами бюллетеня, вероятность 0,03. Выбран первый.

**Направление:** современный средиземноморский редакционный стиль с отсылкой к бумажному путеводителю. **Принципы:** спокойствие, читаемость, прозрачная иерархия, отсутствие ложных обещаний. **Цвет:** тёплый молочный фон, глубокий чернильный текст и терракотовый цвет фокуса, зелёный только для нейтрального прогресса. **Композиция:** просторная левая часть с действиями, узкая правая колонка с контекстом, без равномерной сетки. **Мотивы:** номерные шаги, контур печати и небольшая карточка-напоминание. **Взаимодействия:** очевидные состояния, фокус и быстрый возврат; для переключений короткий fade, для prefers-reduced-motion без анимации. **Типографика:** выразительный Noto Serif для заголовков и Manrope или системный sans для текста, понятный контраст и адаптация к мобильным. **Характер:** надёжный, ясный, внимательный. **Тон:** не бюрократический и не панический. Пример: «Разберём следующий шаг»; «Если свободной записи нет — вот что можно сделать». **Знак:** геометрическое окно с линией, символизирующее открытый путь; логотип не воспроизводит государственные знаки. Фирменный цвет — тёплая терракота #bc563b.
